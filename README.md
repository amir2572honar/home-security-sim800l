# home-security-sim800l
 Arduino Pro Mini + SIM800L Home Security System
First task,register new phone number by send a sms to the sim800l but the sms contain a security code that allows the number to register and send an sms back containing corfirmation text + ask for an ID for this new registered number then wait 3 minute for recevie an sms from that newly registered number containing custom ID and then save ID for that number , otherwise if the number send wrong security code then can not register and sim800l send rejection sms back to the sender phone number. the second task, if a registered number call the sim800l then sim800l must respond with buisy or rejection action to the phone call and then send back a text (security activated + current caller ID) back to the caller and another same text send to the first registered number and execute a function that activate a relay until another phone call receive from any registered number and then send an sms containing (security deactivated + current caller ID number) back to the caller and another but exact same text to the first registerd caller as well and that relay that activated in the last call must deactive untill the next call. Third task, if a registered phone number send an sms containing (status) in the text,then send an sms to that number which containing a text following one of these status if the relay is activated then send (security activated) text to the sender or if that relay is not activated then send (security deactivated) back to the sender.  Four task, if a registered phone number send an sms containing (list) then all registered numbers with saved ID sorted by first registeref to last registered one by one in seprated sms back to the sender phone number. Fifth task, if first registerd phone number send an sms containing (reset) then all registered phone numbers must erased. Sixth task, if to much sms sent from sim800l and it nearly full then delete saved sms to clean up memory for enough room for all functions.
